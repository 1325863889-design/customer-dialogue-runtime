=============== Rag ===========================
索引阶段：
	解析加载
		pdf： UnstructuredPDFLoader
			目标检测模型（识别布局、坐标）
			OCR识别
		表格： minerU -》 转成 markdown

	分块策略
		分隔符递归（chunk size\over lap）  ==> "\n","。"
		大小块（small 2 big）：  
		语义切分： LLM理解，相同语义为一个chunk


	embedding
		MTEB榜单
		Qwen3_embedding 4b \8b(4092d)
		openai： text-embedding

			===>  query -> 中文 -> 32B 


	入库

检索阶段： 
	query-> embedding -> 相似度检索

	精排：rerank（用语义模型打分：组对 打分）
    查询重述
    多查询
    rrf
    hyde：假设性文档 （当检索结果差时，才进入hyde）

检索效率： 缓存
	query -> embedding 
	embedding -> chunks


评估： 
	RAGAS

	指标： 
		精确率 = 检索出来的相关的chunk数 / 检索出来的chunk数
		召回率 = 检索出来的相关的chunk数 / 所有相关的chunk数

		相关100个  检索结果80个  其中50个是相关的
		精确率 = 50/80 
		召回率 = 50/100 


		最少记6个：3+2+1
			三大指标： 
				两个相关性+1个真实性： 
					上下文相关性
					答案相关性
					答案真实性（是否支撑）
			二个经典：
				上下文精确度
				上下文召回率
			一个补充： 
				答案忠诚度（是否曲解）
